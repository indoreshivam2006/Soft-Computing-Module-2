## Requirements

Install Python and Jupyter Notebook. The notebooks use these libraries:

- NumPy
- Matplotlib
- scikit-learn
- TensorFlow / Keras

You can install them with:

```bash
pip install notebook numpy matplotlib scikit-learn tensorflow
```

## How to Run

1. Open the project folder.
2. Start Jupyter Notebook:

```bash
jupyter notebook
```

3. Open the notebooks from `SCP`.
4. Run each notebook cell from top to bottom.

## Purpose

The purpose of this assignment is to understand the basic concepts of Artificial Neural Networks and learn how to build, train, and evaluate neural network models using Python.
